Thor D2 – source code offer (all versions so far: 0.1.0, 0.1.1)

Thor D2 is a fork of D2Android 1.5.2 (https://github.com/N1v0k/D2Android-Releases). It contains the same
third-party free software under the GNU GPL and LGPL, in the same versions; only the package path inside the
runtime differs (tools/build-runtime.py). The list below is D2Android's offer for those parts, unchanged
(the archives are attached to every Thor D2 release on https://github.com/harmssi/thor-d2/releases,
and also mirrored in D2Android's release sources-2-a329647c5f379676 and at their upstream locations).

The complete source of Thor D2 itself – the app including all parts taken over from Winlator (LGPL-2.1) with
D2Android's and Thor D2's changes, the mod and the build scripts – is attached to every Thor D2 release as
thor-d2-<version>-source.tar.gz and is the repository https://github.com/harmssi/thor-d2.

----- D2Android 1.5.2 source code offer (third-party parts) -----

This app contains free software under the GNU GPL and LGPL. For each part below you can get its source code
from the location given, at no charge. Parts marked "best effort" (Wine, glibc, GCC, ALSA) come as the
upstream source of the same version: their exact build cannot be proven byte for byte, and patches the
builder did not publish are not included. All other parts come as their complete corresponding source.
The licence texts are on the page "Licenses" in the app (assets/licenses/).
